# Para onde o Caminho Limpo pode crescer

O produto começa como ferramenta de trabalho para quem vistoria e acompanha o território. A participação pública pode ajudar mais tarde, mas não deve ser necessária para preencher o painel.

## O que existe hoje

Um relato guarda a evidência de um problema: foto, categoria, descrição, endereço, coordenadas, Plus Code e situação. Uma gaiola é outra coisa: representa uma estrutura de coleta mantida pela instituição. Por isso os dois registros não dividem a mesma tabela.

O fluxo atual é curto:

> fotografar → localizar → cadastrar → triar → publicar quando fizer sentido

Os relatos publicados podem aparecer no mural. Os demais continuam disponíveis para a equipe no painel.

## Próxima evolução útil

Depois da validação, vale criar um local consolidado. Ele reuniria relatos próximos, ações realizadas e novas evidências sem apagar o conteúdo original. Isso permitiria responder perguntas simples:

- o problema voltou depois da limpeza?
- quantas vezes esse ponto foi vistoriado?
- quem recebeu o encaminhamento?
- quanto tempo levou até o atendimento?
- existe uma gaiola próxima que pode reduzir a recorrência?

Essa mudança só deve entrar quando a equipe já estiver usando o cadastro atual e souber quais informações realmente consulta.

## Cuidados

O sistema não substitui emergência, fiscalização ou os canais oficiais de uma prefeitura. Também não deve publicar automaticamente coordenadas exatas, rostos, placas ou acusações. A equipe precisa revisar a foto e o texto antes de tornar um relato público.

Dados de contato, caso sejam adicionados, devem ficar separados do conteúdo público. O histórico territorial pode ter valor por mais tempo que os dados pessoais.

## Sinais de que o produto tem valor

- a equipe consegue registrar uma vistoria no celular sem anotar coordenadas;
- o mapa ajuda a planejar uma visita ou coleta;
- os estados do painel refletem o trabalho que está acontecendo;
- os mesmos pontos deixam de ser mantidos em planilhas e conversas paralelas;
- os dados permitem mostrar atendimentos e recorrências com exemplos verificáveis.
